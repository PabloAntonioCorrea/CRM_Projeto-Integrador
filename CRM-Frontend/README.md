# Protótipo de Alta Fidelidade - CRM

## Como rodar

1. Abra a pasta no VS Code.
2. Rode:

```bash
npm install
npm run dev
```

3. Abra o link local exibido no terminal.
4. Tire prints das telas para inserir no documento da Entrega 2.

## Telas incluídas
- Login
- Dashboard
- Lista de Leads
- Cadastro/Edição de Lead
- Funil de Vendas
- Cadastro/Edição de Oportunidade
- Relatórios
- Usuários
- Cadastro/Edição de Usuário
